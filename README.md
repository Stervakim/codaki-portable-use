# Codaki Portable Use

**Версия 0.1.1 — отдельный экспериментальный плагин для работы с Android на виртуальном экране.**

[Инструкция для Codex — основной способ установки](CODEX_INSTALL.md) · [История изменений](CHANGELOG.md)

Codaki Portable Use управляет приложениями и интерфейсом Android на выделенном виртуальном дисплее, не нажимая на физический экран. Python-агент работает с предоставленным владельцем root-доступом; для отдельного режима через ChatGPT нужен собственный зарегистрированный relay и закрытые учетные данные.

## Возможности
- Просмотр окон и доступных приложений, запуск на отдельном экране
- Наблюдение за элементами интерфейса и безопасные нажатия
- Ввод Unicode, навигация и жесты
- Подтверждение действий, журнал запросов, запрет повторного исполнения сомнительных команд
- Автоматическое закрытие собственного виртуального экрана после окончания сеанса
- Режимы: локальный root-only IPC и private relay; Windows-код экспериментальный

## Что изменено в 0.1.1
- Вместо отклонения из-за любого постороннего обновления UI проверяется **сам целевой элемент**: контекст окна, уникальность, видимость, координаты и свойства
- Выполнение привязывается к **актуальному** native fingerprint, который Java проверяет еще раз
- Разрешено безопасное обновление текста вокруг неизменной кнопки и навигация BACK/HOME в том же окне
- Поллинг агента: 3 с → 0,05 с; TTL наблюдения: 30 с → 90 с
- Проверены переходы в Android Settings, кнопки, «Назад» и тесты защитных отказов

## Установка
Главная точка входа: **[CODEX_INSTALL.md](CODEX_INSTALL.md)**. Передайте этот файл Codex на компьютере с подключенным Android. Codex проверит условия, скачает готовый ZIP и выполнит разрешенные шаги.

**Полный установочный ZIP:** [скачать `codaki-portable-use-0.1.1.zip`](dist/codaki-portable-use-0.1.1.zip). В архив включены оба JAR из установленной на телефоне владельца версии 0.1.1. Репозиторий также содержит `core/display-engine.jar` и `core/ui-v2.jar`. Код для автономного relay-подключения нужно конфигурировать отдельно: токены и приватные конфигурации не публикуются.

**SHA-256 ZIP:** `78044082ebfc3ea25abc16008f0bfae0b4545a9c34633e53f23bc034c408920e`.

## Требования
Android с заранее установленными Magisk/root и Termux Python 3.10+ (ssl, sqlite3), ADB на компьютере для установки; ничего не прошивает и не устанавливает root. Не изменяйте VPN, Shadow VLESS, Mini Codex или Android Use.

Частая проверка запросов может повысить расход батареи и сети; при необходимости интервал можно вернуть на 3 с в `src/portable/agent.py`. Подключение к ChatGPT не возникает только от установки модуля: требуется отдельное разрешенное развертывание relay.

## Security
Не публикуйте `agent.json`, `runtime.env`, закрытые токены, состояние `state/`, журналы, скриншоты, архивы из `/data/adb/`. Не перенаправляйте команды на физический экран Android. Уровень безопасности, включая подтверждение неопределенных действий, важнее скорости.
