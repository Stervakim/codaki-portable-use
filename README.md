# Codaki Portable Use 0.1.2b

Управление Android на отдельном виртуальном экране и Windows-приложениями через локальный или закрытый облачный MCP.

**Выпущена 0.1.2b:** исправлены устаревшие наблюдения Windows и отображение версии Android. Доступны новые ZIP для установки и SHA-256; оригинальные 0.1.2 оставлены без изменений.

## Новое в 0.1.2b

- Отдельная регистрация Windows в Sites с собственным ключом; Android-ключ сохраняется.
- До восьми одновременно открытых Windows-сеансов для разных окон с независимыми наблюдениями и сроками действия.
- Общий журнал дедупликации запросов и последовательный ввод на общем рабочем столе.
- Исправлена проверка fingerprint и screenshot перед Windows-вводом.
- Windows-установщик, скрытый запуск агента и задание автозапуска при входе владельца.
- Исходники облачного Worker, регрессионные тесты и полный архив установки.

Сеансы Windows не создают отдельных рабочих столов или аккаунтов. Мышь и клавиатура общие, команды ввода сериализованы. Одно окно принадлежит одному сеансу. Скриншоты и координатный ввод требуют переднего плана. При UNCERTAIN сначала проверьте результат и выполните reconciliation; не повторяйте ввод.

Весь пакет поставляется без приватных agent-конфигураций, ключей, журналов и состояния устройств. Установка сама по себе не создаёт связь с ChatGPT: Codex должен развернуть собственный закрытый relay, зарегистрировать устройство и подтвердить online и ответы UI-команд. Windows нужен Python 3.10+ и разблокированная интерактивная сессия; Android — заранее установленный Magisk/root и Termux Python.

Android-настройки, VPN, Mini Codex и Android Use не меняются при Windows-установке. Проверенные Android JAR сохранены из 0.1.1. Лицензия MIT.
