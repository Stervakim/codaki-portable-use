# INSTALL WITH CODEX — Codaki Portable Use 0.1.1

## Что делать Codex

Пользователь предоставляет ЭТОТ файл Codex, работающему на ПК с подключенным Android, и поручает установить или обновить **Codaki Portable Use**, не затрагивая другие программы. Репозиторий: https://github.com/kalabuxova1-hash/codaki-portable-use

**Цель:** установить плагин из проверенных исходников безопасно. Работай самостоятельно, но **не делай необратимых изменений без подтверждения**; перед возможной перезагрузкой обязательно спроси владельца.

### 1. Проверка

1. Скачай репозиторий из GitHub. Проверь структуру файлов и сравни версию `magisk/module.prop` (ожидается 0.1.1).
2. Проверь доступность `adb devices` и явно разрешенного устройства владельца.
3. Проверь root через `adb shell su -c id`, наличие Magisk и уже установленного Termux Python 3.10+ с `ssl` и `sqlite3`.
4. **Никогда** не устанавливай Magisk или root самостоятельно. Не меняй VPN, сеть, VLESS, Android Use, Mini Codex, launcher, политики безопасности или физический экран.
5. Проверь, установлен ли `/data/adb/modules/codaki_portable_use`. Если уже установлен, не запускай новую установку поверх него: сохрани существующую конфигурацию, сделай резервную копию и согласуй безопасное обновление. `customize.sh` намеренно блокирует небезопасное наложение.

### 2. Подготовка бинарных Android-компонентов

Этот GitHub-репозиторий содержит **исходники**. Два необходимых Android Java JAR пока не включены: `display-engine.jar` и `ui-v2.jar`.

**Найди и проверь их из доверенного исходника, указанного владельцем, либо собери из соответствующего проверенного Java-исходного кода.** Для ремонта *уже установленного* экземпляра допустимо использовать именно его существующие локальные JAR с согласия владельца, проверив их целостность. Не загружай их на публичные сайты автоматически.

Если компонентов нет или происхождение сомнительно — **остановись и объясни, что сборка не готова**. Нельзя скачивать случайные файлы, подменять Android Use JAR без проверки совместимости или объявлять установку завершенной.

### 3. Сборка на ПК

Если два доверенных JAR доступны, из корня проекта:

```sh
python3 scripts/build_module.py --display-jar /ABS/PATH/display-engine.jar --ui-jar /ABS/PATH/ui-v2.jar --output codaki-portable-use-0.1.1.zip
```

Проверь ZIP: должны присутствовать `module.prop`, `customize.sh`, `service.sh`, `stop.sh`, `uninstall.sh`, `runtime/portable/*.py`, `core/display-engine.jar`, `core/ui-v2.jar`. Не помещай в архив токены, приватный конфиг и журналы.

### 4. Установка **на новое устройство** (после проверок)

```sh
adb push codaki-portable-use-0.1.1.zip /data/local/tmp/codaki-portable-use-0.1.1.zip
adb shell su -c 'magisk --install-module /data/local/tmp/codaki-portable-use-0.1.1.zip'
```

Синтаксис установки Magisk уточни на устройстве. Если приложение Magisk требует установку через интерфейс, не подменяй его неофициальными командами.

Установщик оставляет модуль **остановленным** и не создает приватные relay-токены. Сначала проверь `/data/adb/modules/codaki_portable_use`, `/data/adb/codaki-portable-use/app` и права. Согласуй перезагрузку с владельцем, если она требуется.

### 5. Режим и связь с ChatGPT

- Локальный режим: без `agent.json` запускается `portable local` с доступом через **root-only** Unix socket.
- Для управления **через ChatGPT** потребуется собственное корректно настроенное HTTPS relay, регистрация плагина и приватный `agent.json` (схема: `magisk/agent.example.json`). Не выдумывай сервер, токен и не копируй их из других установок без разрешения.
- Конфигурация должна храниться только на устройстве с правами 0600. Не публикуй данные в GitHub, логи, чат или отчет.

### 6. Проверка

После разрешенного запуска проверь отсутствие конфликтующих агентов, наличие изолированного дисплея и работу управления: создать сессию, открыть Настройки, прочитать элементы, нажать «О телефоне», вернуться назад, закрыть сессию. Нельзя проводить тестовую отправку сообщений, платежи или редактирование приватных данных.

Подтверди **фактический** результат. Разделяй «модуль установлен», «служба работает», «UI-команды работают» и «подключение через ChatGPT готово». Сохрани способ отката и путь бэкапа.

### Безопасность

Действия только на виртуальном дисплее. Для спорных нажатий осматривай интерфейс и не повторяй команду без проверки; `SEMANTIC_NOT_CONFIRMED` означает неопределенный результат. Существующие данные и настройки никогда не удаляй ради успешной установки.
