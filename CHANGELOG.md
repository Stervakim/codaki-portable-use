# История изменений

## 0.1.1 — 2026-10-11
- Устранены ложные STA​​LE для семантически неизменной цели при посторонних обновлениях экрана
- Проверки по-прежнему отклоняют изменение активного окна, смещенные и неоднозначные цели
- Действие привязывается к текущему native fingerprint
- Навигация BACK/HOME допускает обновление содержимого при том же активном окне
- TTL наблюдения увеличен с 30 до 90 секунд
- Интервал опроса команд уменьшен с 3.0 до 0.05 секунды
- Локальные защитные тесты и проверка Settings / About / Back прошли; полного длительного нагрузочного теста пока нет
